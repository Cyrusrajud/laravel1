### How It Works?
1. You click the "+ Add Task" button
2. Laravel shows you a blank form for creating a new task
3. You fill in a task name, description, due date, then click "Save Task"
4. Laravel checks your input
5. Laravel saves it to the database
6. Laravel sends you back to the task list
7. Laravel grabs every task from the database
8. The page displays the updated list
9. Clicking the toggle button will switch a task between Pending/Completed
10. Clicking the edit button opens a form will filled with that task details so you can update it
11. Clicking the delete button will remove a task from the list
